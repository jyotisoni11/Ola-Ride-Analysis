# 🚖 Ola Ride Analysis

## 📌 Project Overview

This project analyzes **Ola ride booking data** to understand ride performance, revenue, cancellations, customer behavior, and vehicle-type trends.

The analysis was performed using **SQL and Power BI**, with an interactive dashboard created to present important business insights in an easy-to-understand way.

---

## 🛠️ Tools & Technologies

* **SQL** – Data analysis and business queries
* **Power BI** – Interactive dashboard and data visualization
* **CSV** – Dataset

## 📊 Dashboard

The Power BI dashboard provides different sections for analyzing Ola rides:

* **Overall** – Overall ride and business performance
* **Vehicle Type** – Analysis by different vehicle categories
* **Revenue** – Revenue and booking-related analysis
* **Rating** – Customer rating analysis
* **Cancellation** – Ride cancellation analysis

The dashboard includes interactive navigation buttons that allow users to move between different analysis pages.
